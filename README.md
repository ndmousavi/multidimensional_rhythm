# Representing Multidimensional Speech Rhythm

This repository contains the analysis code associated with the manuscript:

**Representing multidimensional speech rhythm: Comparing latent-dimensional and feature-based modelling of Persian rhythm**, Neda Mousavi

The study investigates multidimensional speech rhythm using two complementary approaches: Principal Component Analysis (PCA) and correlation-based feature selection. Linear mixed-effects models are used to assess rhythmic variation across seven speaking tasks while accounting for individual speaker differences. The analysis includes 28 rhythm measures spanning duration, fundamental frequency (F0), and intensity.
